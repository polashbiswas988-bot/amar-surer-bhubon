আমার সুরের ভুবন — Pro (পরীক্ষামূলক সংস্করণ)
===========================================
ফাইল:
- index.html : অ্যাপের পৃষ্ঠা
- style.css : ডিজাইন
- app.js : শব্দ, ৩৭টি কী, রাগ পাঠ, স্বরলিপি, ব্যাকআপ
- manifest.json : ফোনে ইনস্টল করার তথ্য
- sw.js : অফলাইনে পৃষ্ঠা খোলার ক্যাশ
- icons/ : আগের GitHub-এ থাকা পল্লবীর ছবির আইকন ব্যবহার করা হবে; নতুন ZIP-এর icons ফোল্ডার আপলোড করার দরকার নেই।

চালু:
1. ফাইলগুলো একসঙ্গে রাখুন।
2. GitHub repository-র মূল পাতায় index.html, app.js, style.css, manifest.json, sw.js আপলোড করে পুরোনো ফাইলগুলো replace করুন (ZIP ফাইল নয়)। আগের icons ফোল্ডারটি মুছবেন বা replace করবেন না—এতে পল্লবীর ছবির আইকন থাকবে।
3. Settings > Pages-এ Branch main এবং Folder /(root) দিন।
4. ওয়েবসাইট Chrome-এ খুলুন। প্রথমবার অনলাইনে খোলা অবস্থায় কয়েক সেকেন্ড রাখুন, যাতে ফাইল ক্যাশ হয়।
5. ফোনে Chrome-এর menu থেকে Install app / Add to Home screen ব্যবহার করুন।

সীমাবদ্ধতা:
- হারমোনিয়াম/বাঁশি/বীণার শব্দ Web Audio দিয়ে তৈরি করা শিক্ষামূলক কৃত্রিম শব্দ, আসল রেকর্ড করা নমুনা নয়।
- রাগের ছোট অডিও উদাহরণগুলো স্বর-ধাঁচের প্রাথমিক অনুশীলন; এগুলো পূর্ণাঙ্গ শাস্ত্রীয় পরিবেশনা নয়। রাগের চলন ঘরানা ও শিল্পীভেদে ব্যাখ্যায় পার্থক্য থাকতে পারে।
- অফলাইন ক্যাশিং প্রথমবার অনলাইনে খোলার পরে কার্যকর হবে।
- Google Fonts ইন্টারনেট থাকলে ব্যবহার হবে; অফলাইনে ডিভাইসের fallback font ব্যবহৃত হবে।
